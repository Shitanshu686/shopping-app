Who We Are

About ShopEase

ShopEase is a full-stack e-commerce application developed to simulate a modern online shopping platform.

The application provides complete customer and administrator workflows, including product discovery, authentication, shopping cart, wishlist, checkout, orders, payments, product ratings and inventory management.

The project focuses on building a production-oriented application using a modular architecture where frontend, backend, database, security and payment components work together through REST APIs.

Technology

Technology Stack

Frontend

HTML, CSS, JavaScript, Fetch API and LocalStorage.

Backend

Java, Spring Boot, Spring MVC, Spring Data JPA and Hibernate.

Security

Spring Security, JWT authentication and BCrypt password hashing.

Database

MySQL with Spring Data JPA and Hibernate.

Payments

Razorpay payment integration with payment verification and handling.

DevOps

Git, GitHub, Docker, Docker Compose and GitHub Actions.

Capabilities

What ShopEase Offers

🛍️ Shopping Experience

Product search, categories, advanced filtering, sorting, pagination, product details and similar products.

🔐 Secure Authentication

JWT-based authentication, BCrypt password hashing and role-based authorization for users and administrators.

🛒 Cart & Wishlist

Persistent shopping cart and wishlist functionality for authenticated users.

📦 Orders

Checkout, shipping address, order history, order details and order status management.

💳 Online Payments

Razorpay integration with payment order creation, amount validation and signature verification.

⭐ Product Ratings

Verified buyers can rate purchased products after successful order delivery.

👨‍💼 Admin Management

Admin dashboard with product, user, order and inventory management.

🖼️ Product Images

Admin product image upload with unique filenames and server-side image storage.

🐳 Containerization

Docker and Docker Compose based backend and MySQL container environment.

Engineering

Built With Production In Mind

REST API Architecture

Frontend communicates with the Spring Boot backend through REST APIs.

Validation & Exception Handling

Backend validation and centralized exception handling provide consistent API behaviour.

Logging

Application logging is implemented using SLF4J and Logback.

Pagination & Sorting

Server-side pagination and dynamic sorting are implemented using Spring Data JPA.

CI Pipeline

GitHub Actions is configured to automatically build and test the application.
